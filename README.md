# Alrededor de los EE.UU. - Proyecto React

Este proyecto es una adaptación del sitio web **"Alrededor de los EE.UU."** construido previamente con HTML y CSS, ahora reestructurado usando **React** y **Vite**.

## Tecnologías

- React
- Vite
- JavaScript moderno (ES6+)
- CSS Modularizado

## Funcionalidades

- Visualización de tarjetas con imágenes y descripciones.
- Ventanas emergentes para:
  - Editar perfil
  - Actualizar avatar
  - Agregar una nueva tarjeta
  - Ver imagen en tamaño completo
  - Confirmar eliminación de tarjeta
- Componentes reutilizables
- Uso de `useState` para manejar interactividad

## Estructura del proyecto

- `components/`: Contiene todos los componentes organizados por funcionalidad.
- `images/`: Recursos gráficos del sitio.
- `blocks/`: Archivos CSS reutilizables.
- `src/index.css`: Estilos globales.

## Cómo ejecutar

```bash
npm install
npm run dev
```
